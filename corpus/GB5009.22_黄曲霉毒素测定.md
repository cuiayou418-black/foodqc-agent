## 1　范围

测定 **AFB1、AFB2、AFG1、AFG2** 四种毒素。

### 五种方法与适用范围（⚠️ 全部包含「油脂及其制品」）

| 方法 | 技术路线 | 测定组分 | 适用范围 |
|---|---|---|---|
| **第一法** | 同位素稀释液相色谱-**串联质谱** | AFB1、B2、G1、G2 | 谷物及其制品、豆类及其制品、坚果及籽类、**油脂及其制品**、调味品、婴幼儿配方食品和婴幼儿辅助食品 |
| **第二法** | 高效液相色谱-**柱前衍生** | AFB1、B2、G1、G2 | 同上 |
| **第三法** | 高效液相色谱-**柱后衍生** | AFB1、B2、G1、G2 | 同上 |
| **第四法** | **酶联免疫吸附筛查法** | 仅 AFB1 | 同上 |
| **第五法** | **薄层色谱法** | 仅 AFB1 | 谷物、豆类、坚果及籽类、**油脂及其制品**、调味品（不含婴幼儿食品） |

## 2　原理（第一法，原文）

> 试样中的 AFB1、AFB2、AFG1、AFG2，用**乙腈-水溶液或甲醇-水溶液**提取，提取液用含 **1% Triton X-100（或吐温-20）的磷酸盐缓冲溶液**稀释后（必要时经黄曲霉毒素固相净化柱初步净化），通过**免疫亲和柱净化和富集**，净化液浓缩、定容和过滤后经**液相色谱分离，串联质谱检测，同位素内标法定量**。

### 流程链（5 步）
```
提取（乙腈-水 84:16 或 甲醇-水 70:30）
  → PBS 稀释（含 1% Triton X-100）
  → 免疫亲和柱净化富集（必要时先用固相净化柱）
  → 浓缩定容过滤
  → 液相色谱分离 + 串联质谱检测（同位素内标法定量）
```

### 关键试剂与配方（原文抄录）
| 项目 | 规格 / 配方 |
|---|---|
| 乙腈、甲醇 | **色谱纯** |
| 乙酸铵 | 色谱纯 |
| 乙腈-水溶液（84+16） | 840 mL 乙腈 + 160 mL 水 |
| 甲醇-水溶液（70+30） | 700 mL 甲醇 + 300 mL 水 |
| 乙腈-水（50+50）/ 乙腈-甲醇（50+50） | 各按等体积混合 |
| 10% 盐酸溶液 | 1 mL 盐酸 + 纯水稀释至 10 mL |
| **磷酸盐缓冲液 PBS** | 8.00 g NaCl + 1.20 g Na₂HPO₄（或 2.92 g 十二水磷酸氢二钠）+ 0.20 g KH₂PO₄ + 0.20 g KCl，用 900 mL 水溶解，**用盐酸调节 pH 至 7.4±0.1**，定容至 1000 mL |
| 1% Triton X-100 的 PBS | 取 10 mL Triton X-100（或吐温-20），用 PBS 稀释至 1000 mL |
| 水 | **GB/T 6682 规定的一级水** |

## ⚠️ 实务要点（来自检验机构公开解读，非标准原文，供操作参考）

- **取样量**：液体样品 >1 L；袋装/瓶装需至少取 3 个包装；取样后混匀，任意取 100 g(mL) 检测。
- **黄曲霉毒素属致癌物**，操作须穿戴手套口罩实验服；标准器具与手套需用 10% 次氯酸钠水溶液浸泡处理。
- **免疫亲和柱使用前须验证**柱容量、柱回收率、交叉反应率；AFB1 柱容量 ≥160 ng，高含量样品需减少上样量防过载。
- **柱后衍生荧光检测**定量限约 0.1 μg/kg，对仪器灵敏度要求高，建议专机专用。
- 判定风险来源：气候环境、**原料采购未严挑未检测**、采收储运条件不当、加工精炼程度不够。
