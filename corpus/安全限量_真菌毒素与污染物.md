# 食用油安全限量：真菌毒素 + 污染物（语料）

> 数据来自 **GB 2761—2017** 与 **GB 2762—2025** 的限值表，经 PDF 页面渲染后**逐格核对**。
> 用途：食用油中**非酸价/过氧化值类**的安全指标判定。

---

## 一、黄曲霉毒素 B₁（GB 2761—2017 表 1）⭐

> **单位：μg/kg**　|　**检验方法：按 GB 5009.22 规定的方法测定**（原文 4.1.2）

### 食用油及其制品

| 食品类别 | 限量（μg/kg） |
|---|---|
| **植物油脂（花生油、玉米油除外）** | **10** |
| **花生油、玉米油** | **20** |

> ⚠️ **易错点**：花生油、玉米油的黄曲霉毒素 B₁ 限值**更严（20）**，与其他植物油脂（10）不同。
> 原因是这两类油料**天然易受黄曲霉污染**，风险更高。

### 其他相关类别（供参考）

| 类别 | 食品 | 限量（μg/kg） |
|---|---|---|
| 谷物及其制品 | 玉米、玉米面（渣、片）及玉米制品 | 20 |
| | 稻谷、糙米、大米 | 10 |
| | 小麦、大麦、其他谷物 | 5.0 |
| 豆类及其制品 | 发酵豆制品 | 5.0 |
| 坚果及籽类 | 花生及其制品 | 20 |
| | 其他熟制坚果及籽类 | 5.0 |
| 调味品 | 酱油、醋、洋葱酱 | 5.0 |

> 📌 标准还规定了**黄曲霉毒素 M₁（表 2）**、**赭曲霉毒素 A（表 3）** 等限量，食用油场景主要关注 **B₁**。
> ⚠️ 表 2、表 3 本次未逐格核对，如需使用请回查 PDF 原文。

## 二、铅（GB 2762—2025 表 1）

> **单位：mg/kg（以 Pb 计）**　|　**检验方法：包装饮用水按 GB 8538，其他食品按 GB 5009.12 测定**（原文 4.1.2）

| 食品类别 | 限量（mg/kg） |
|---|---|
| **油脂及其制品** | **0.08** |
| 蔬菜及食用菌 | 0.1 |
| 谷物及淀粉类制品 | 0.5 |
| 蛋及蛋制品 | 0.2 |
| 肉及肉制品 | 0.2~0.5 |
| 水产动物及其制品 | 0.5~2.0 |
| 乳及乳制品 | 0.02~0.2 |
| 可可制品、巧克力 | 0.5 |
| 冷冻饮品 | 0.3 |
| 调味品（不含香辛料类） | 1.0 |

> ⚠️ **为什么油脂类铅限量特别严（0.08）**：铅是**可以从原料带入、且难以在精炼中去除**的重金属，
> 压榨工艺尤其容易把油料中的铅带入成品油。这是**原料风险型指标**，不同于酸价/过氧化值那类**过程劣化型指标**。

## 三、指标分类速记（Agent 判读时用）

| 类型 | 典型指标 | 风险来源 | 能否靠精炼去除 |
|---|---|---|---|
| **过程劣化型** | 酸价、过氧化值 | 原料不新鲜、储存不当、加工温度高 | 可部分改善 |
| **原料带入型** | 铅、黄曲霉毒素 B₁ | 油料被污染、土壤/霉变 | **难去除**，靠原料筛选与检验拦截 |

> 📌 这个分类对应毕设「**根因溯源**」两条完全不同的路径：
> - 酸价/过氧化值异常 → 回溯**加工与储存**环节（见 GB 8955 附录 A 表 A.2）
> - 铅/黄曲霉毒素异常 → 回溯**原料批次与供应链**环节
