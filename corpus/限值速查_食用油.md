## 0. 最重要的一个坑：两条标准并行，别搞混

| | **GB 2716—2018** | **GB/T 1535—2026** |
|---|---|---|
| 名称 | 食品安全国家标准 **植物油** | **大豆油** |
| 属性 | **强制性**食品安全标准（GB） | **推荐性**产品标准（GB/T） |
| 管什么 | 所有"食用植物油"的**整体安全限量** | 大豆油的**分级质量指标** |
| 酸价 | 食用植物油 ≤ **3** mg/g | 一级浸出 ≤ **0.50** mg/g |
| 生效 | 2018-12-21 | **2026-08-01 起实施**（代替 2017 版） |

> 📌 **判定逻辑**：GB 2716 是"底线"，GB/T 1535 是"分级线"。产品标准更严时从其规定。一级大豆油按 0.50 判，不是 3。

## 3. 术语定义（引自 GB/T 1535—2026 第 3 章）

- **酸价（3.10）**：中和 1g 油脂中所含游离脂肪酸需要的氢氧化钾毫克数。
- **过氧化值（3.11）**：过氧化物相当于碘的质量分数。
- **水分及挥发物（3.8）**：在一定温度条件下，油脂中所含的微量水分和挥发物的质量分数。
- **不溶性杂质（3.9）**：油脂中不溶于石油醚等有机溶剂的物质的质量分数。

## 4. 单位陷阱（模型最容易在这里翻车）

| 指标 | 标准写法 | 常见错误 | 换算 |
|---|---|---|---|
| 酸价 | **mg/g（以 KOH 计）** | ❌ 写成 "%"、❌ 误加单位到数值上 | 1 mg/g = 1 mg KOH/g，数值相同 |
| 过氧化值 | **g/100g** | ❌ 误当作百分比（虽然数值可读成 %，但单位表述必须是 g/100g） | 0.13 g/100g 即常说的"0.13" |

> 📌 **Day2 幻觉的正确数字**：一级浸出大豆油酸价 = **0.50 mg/g（以 KOH 计）**，依据 **GB/T 1535—2026 表 4**。
> 模型当时答的 0.20 是编的；`0.20` 这个数字实际对应的是 **GB 2716 表 2 中植物原油（非米胚油等）的酸价上限**——张冠李戴，正是幻觉的典型形态。

## 5. 标准判定链（Agent 组织解释时的骨架）

1. **确认油品类别**：大豆原油 / 压榨大豆油 / 浸出大豆油
2. **确认质量等级**：一级 / 二级 / 三级（未标等级 → 按 GB/T 1535 8.4.1 判为不符合）
3. **取限值**：按对应表（表 2 / 表 3 / 表 4）
4. **实测**：酸价按 GB 5009.229、过氧化值按 GB 5009.227
5. **判定**：实测 ≤ 限值 → 合格；＞ 限值 → 不合格
6. **兜底**：缺任一必要信息 → 输出「数据不足，需补充：xxx」，**禁止推算**
