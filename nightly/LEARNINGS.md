# B 站学习笔记（夜间巡检自动累积）

> 小崔白天翻这一份就够了。**记录标准：看了什么 → 讲了什么 → 能用到哪。**
> 禁止写"学习了""很受启发"这类空话；写不出"能用在哪"，就写"暂用不上，什么时候再看"。

## 写法

**先给来源分级，不同级别写不同的把握程度。**

| 级别 | 来源 | 能不能写进笔记 | 必须标注 |
|---|---|---|---|
| **A** | 视频正文（BibiGPT 摘要 / 字幕） | 可以当事实写 | `（A·已看正文）` |
| **B** | 简介 + **评论区/弹幕里的省流、高赞补充** | 可以写，但要当"二手线索" | `（B·评论区省流，未看正文）` |
| **C** | 只有标题 | **只许记录"有这么个视频、指向某个方向"**，不许复述内容 | `（C·仅标题）` |

**B 级不是没用——恰恰相反**，很多 up 主会把步骤写在置顶评论里，质量比正文还高。
但 B 级有两种坑：① 省流是人写的，会漏会错；② 高赞可能是段子。
所以 B 级的用法是「**顺着这条线索白天自己去看**」，不是「拿它当结论」。

挑评论时只挑：**高赞 + 有具体步骤/具体数字**的。纯情绪、纯玩梗的跳过。

```
### 第 N 轮 · 搜索关键词
- **看了什么**：视频标题（UP主）· 时长 · 来源级别 A/B/C
- **讲了什么**：三句以内，说人话
- **能用在哪**：对应 /app 对话、任务卡、检索、报告、演示 的哪个环节；用不上就写"暂用不上，什么时候再看"
- **反过来想**：别人踩的坑，我们有没有
```
